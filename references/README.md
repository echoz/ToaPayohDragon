# Reference records

Photographs informed the arrangement and silhouette of the original playground. They are visual references, not a measured survey. The model is a stylized interpretation.

The [Commons attribution record](ATTRIBUTION.md) lists each source page, photographer and recorded license. [manifest.json](manifest.json) and [supporting-manifest.json](supporting-manifest.json) preserve research provenance, including local filenames from the authoring workspace. No photograph or downloaded source-page HTML is included in this public checkout or the printable kit. Local path fields in these historical records do not identify files available in a clone; use their source URLs.

The supporting photographs without established redistribution permission remain local. Follow each original publisher’s terms when accessing their images. Recorded photograph licenses apply to those source photographs, not automatically to this model or its source code.
